Wireshark Network Analysis

Overview

This repository documents my hands-on learning of computer networking and packet analysis using Wireshark as part of my preparation for a SOC Analyst internship.

The goal is to understand how network communication works and how packet analysis can support security monitoring and investigation.

Objectives

Understand basic network communication.

Identify source and destination IP addresses.

Examine TCP and UDP traffic.

Understand TCP connection establishment.

Practice Wireshark display filters.

Learn how packet analysis supports security investigations.

Security Relevance
Packet analysis can help security analysts investigate unusual connections, identify communication patterns, and collect evidence during network security investigations.

A single packet or IP address does not establish malicious activity. Findings must be evaluated in context.
